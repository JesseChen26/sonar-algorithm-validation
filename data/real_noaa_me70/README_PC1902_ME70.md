# Using the PC1902 ME70 Raw Dataset
## Data 
 
 Each file is a binary formatted instrument file. Kongsberg/Simrad .raw files are generated by ME70, EK60, EK80 or ES60 instruments. They contain power and optionally angular position data with each beam/frequency identified by an independent channel. The .wcd files are generated by Kongsberg EM302, EM122 or EM710 instruments. Additional file types from other instruments exist in this bucket. See instrument specific documentation for more information.
## Storage Structure 
 
The name of this AWS bucket is noaa-wcsd-pds. Raw data files in this bucket are primarily organized by ship name, cruise ID, then instrument name with ship names in camel case and cruise IDs and instrument names in uppercase. If data was collected by a stationary recorder (i.e. bottom lander), the organizational structure is by project, deployment ID, then instrument name. Processed data are under the processed directory and organized by dataset name and source organization.
 
**Path Structures** 
 
* s3://noaa-wcsd-pds/data/raw/ship name/cruise ID/instrument name/ 
* s3://noaa-wcsd-pds/data/raw/Stationary_Recorder/project/deployment ID/instrument name/ 
* s3://noaa-wcsd-pds/data/processed/dataset name_source organization/
 
**Path to this dataset**
 
* s3://noaa-wcsd-pds/data/raw/Pisces/PC1902/ME70/
 
## Downloading Data 
 
 To download files using the command line, first install the [AWS CLI](https://aws.amazon.com/cli/) tool. Then use the following command, replacing *destination path* with your desired download location.
 
*aws s3 cp s3://noaa-wcsd-pds/data/raw/Pisces/PC1902/ME70/ destination path --recursive --no-sign-request*
