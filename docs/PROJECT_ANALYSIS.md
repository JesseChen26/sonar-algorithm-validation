# 水声算法仿真项目结果分析

## 当前结论

第二版仿真结果比第一版更接近工程测试场景：目标距离和角度不再正好落在网格上，并加入弱目标、多径副本、杂波和更强背景噪声。算法链路仍能跑通，但结果不再“完美命中”。

## CFAR 检测结果

`target_A` 和 `target_B` 被正确检测：

- `target_A`：距离误差约 `0.06 m`，角度误差约 `-0.4 deg`
- `target_B`：距离误差约 `-0.06 m`，角度误差约 `-0.4 deg`

`target_C` 为弱目标，检测峰值被海底/杂波强回波带偏，判定为 `mismatch`：

- 距离误差约 `7.06 m`
- 角度误差约 `-33.7 deg`

这说明当前 baseline 的主要问题不是代码跑不通，而是弱目标在强背景和旁瓣干扰下容易被误匹配。

## 参数敏感性

噪声强度变化对结果影响不明显，原因是当前错误主要来自海底强回波、杂波和弱目标竞争，而不是白噪声主导。

阵元数量对结果影响明显：

- 4-6 阵元时，平均误差显著增大；
- 8 阵元以上，角分辨能力改善，两个强目标可稳定命中；
- 弱目标仍需要更强的检测策略，例如旁瓣抑制、局部背景建模或目标先验约束。

## 后续可改进方向

1. 对波束形成结果加入旁瓣抑制，例如加窗或自适应波束形成。
2. 在 CFAR 后加入距离/角度门限、连通域聚类和目标尺寸约束。
3. 对侧扫图像补充 TVG、声影长度估计和目标-声影联合检测。
4. 接入真实 XTF/JSF 或多波束水柱数据，验证仿真算法在真实噪声和海底背景下的表现。

## 简历表述

基于单/多波束声呐工作流程构建小型算法验证项目，模拟阵列原始复数回波、海底线、目标强回波、弱目标、多径和杂波数据；实现 delay-and-sum 波束形成、距离-角度成像、二维 CFAR 检测、底线检测和斜距校正，输出回波瀑布图、成像图、检测结果图和参数敏感性曲线；基于目标真值评估距离/角度误差，分析弱目标在强海底回波和旁瓣干扰下的误匹配问题，并提出旁瓣抑制、聚类约束和真实声呐数据验证等改进方向。
